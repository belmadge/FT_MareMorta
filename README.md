# FT_MareMorta

**FerroTech Game Studio** — first-person psychological horror inspired by contemporary Maceió, Alagoas.

> Maceió nunca esqueceu. O mar também não.

## Project documentation

- [Game Design Document (GDD)](docs/GDD.md)
- [Definitive map proposal](docs/MAPA.md)

## Approved creative direction

- Present-day Maceió with fictional supernatural events.
- Recognizable real-world geographic and cultural references, with fictional in-game place names.
- Family mystery connected to the fictional hidden history of the city.
- Unreal Engine 5; Windows PC / Steam target.
- Single-player, first-person psychological survival horror.
- Target playtime: 2–3 hours.

## Map proposal

Five compact zones: Vila do Sal, Pousada Brisa Baixa, Cais das Pedras, Baixio and Abaixo. These are fictional locations inspired by Maceió's coastal, lagoon and port environments; they are not real addresses or claims about actual events.

See the GDD and map proposal for narrative, gameplay, technical direction, production scope and level-design constraints.
