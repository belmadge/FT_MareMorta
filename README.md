# FT_MareMorta

**FerroTech Game Studio** — first-person psychological horror inspired by Maceió, Alagoas.

## Project documentation

- [Game Design Document (GDD)](docs/GDD.md)

## Current direction

- Unreal Engine 5
- Windows PC / Steam target
- Single-player, first-person psychological survival horror
- Target playtime: 2–3 hours
- Fictionalized Maceió setting, drawing respectfully on Jaraguá, Lagoa Mundaú, Pontal da Barra and the reef coastline

See the [GDD](docs/GDD.md) for the concept, narrative, gameplay pillars, level plan, technical direction, scope and production milestones.
